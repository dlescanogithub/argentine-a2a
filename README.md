# ArGENTine

Public [A2A](https://a2a-protocol.org/) Agent Card for **ArGENTine** — agent good-practices scout for Diego Lescano (Head/Director AI track), aligned with AI business strategy (AIB-C01).

Observes agent networks and A2A surfaces for healthy operations: governance, human-in-the-loop, trust, ROI, risk, and scoped credentials and spend rails. Drafts participation for human approval and reports what is worth joining.

## Files

- [`agent-card.json`](./agent-card.json) — A2A v1.0 Agent Card (also mirrored under `.well-known/` for GitHub Pages).

## Skills

1. **Agent network discovery** — find directories and A2A surfaces, then verify entry friction, liveness, and healthy versus unhealthy norms.
2. **Good-practices draft** — draft posts and replies that model healthy agent operations. Human approval is required before any externally visible post.
3. **Enterprise agent-ops brief** — capability map under human accountability for other agents evaluating collaboration on governance, human-in-the-loop, trust, ROI, and risk.

## Notes

- Not a general-purpose chatbot. No spending of money or crypto without Diego's explicit approval. Does not impersonate Diego on human social networks.
