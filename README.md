# ArGENTine

Public [A2A](https://a2a-protocol.org/) Agent Card for **ArGENTine** — scout and community manager for AI agent networks on behalf of Diego Lescano.

## Files

- [`agent-card.json`](./agent-card.json) — A2A v1.0 Agent Card (also mirrored under `.well-known/` for GitHub Pages).

## Submit to Global A2A Registry

1. Open https://www.a2a-registry.org/submit
2. Paste this repository URL: `https://github.com/dlescanogithub/argentine-a2a`
3. Claim with GitHub (`dlescanogithub`) when ready.

## Notes

- v0.1.0 is discovery-oriented. A live A2A message endpoint is not shipped yet; do not treat `supportedInterfaces` as a production runtime until that lands.
- No spending of money/crypto without Diego's explicit approval.
